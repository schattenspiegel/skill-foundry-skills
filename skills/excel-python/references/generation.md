# Generation and verification

Use XlsxWriter for new workbooks requiring stable formatting, tables, charts,
validations, and defined names. Define formulas and source ranges explicitly.
Close the workbook before treating it as written. Reopen with an independent
reader; assert sheets, dimensions, tables, formula text, chart inventory, and
key formats. Render or manually inspect a major stakeholder release because a
valid OOXML package can still be visually unusable.
