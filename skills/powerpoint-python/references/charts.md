# Charts

Use a native PowerPoint chart only when recipients must edit its data, a
corporate template requires it, or downstream PowerPoint manipulation is part
of the contract. Otherwise render complex analytical charts externally at
appropriate resolution and insert them as images.

Native chart data comes from typed resolved inputs. State series names,
categories and order, units, number formats, title/axis semantics, reference
lines, legend placement, and any justified secondary axis. Treat the embedded
workbook as part of the artifact and include it in preservation comparison.

Do not recalculate analysis inside chart-construction code or create a chart
merely because a table has several columns.
