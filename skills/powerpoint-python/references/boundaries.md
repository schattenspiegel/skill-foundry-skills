# Boundaries and routing

| Required result | Owner |
|---|---|
| Supported `.pptx` package inspection/generation/editing | `powerpoint-python` |
| Cautious `.pptm` inventory and proven preservation | `powerpoint-python` |
| Data preparation, ranking, aggregation, statistical computation | Relevant data/analysis skill |
| Storyline coaching without Python or a presentation file | Presentation-design workflow |
| Native PowerPoint open/save/render/PDF, animations, media, accessibility checker | Future `powerpoint-runtime` |
| `.ppt` binary manipulation | Out of scope |

Do not broaden a supported edit into a package rewrite. Runtime availability is
not implicit authority to run macros, actions, media, programs, external links,
or add-ins. When exact unsupported behavior matters, retain the source and stop
with the missing evidence named.
