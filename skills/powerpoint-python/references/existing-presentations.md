# Existing presentations

1. Preserve the original and choose a new destination.
2. Inventory package, slides, layouts/masters, relationships, notes, active
   content, and preservation-sensitive parts.
3. Classify required equivalence and library support.
4. Mutate only the smallest supported region.
5. Reopen and run semantic before/after diff.
6. Render and visually inspect affected plus representative unaffected slides.

Do not clone a slide by copying XML between packages. Reconstruct supported
content against the destination template or use an authorized PowerPoint-native
copy when exact relationship-aware copying is required.

Successful save and unchanged part presence do not prove animations, SmartArt,
media, actions, or layout fidelity.
