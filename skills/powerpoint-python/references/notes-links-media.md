# Notes, links, and media

Inventory whether each slide has a notes part and meaningful notes text. An
unrelated edit must not silently discard speaker notes. Keep visible content,
speaker notes, and internal metadata distinct.

Classify hyperlinks as internal-slide or external. Inspect click/action settings
for hyperlink, `OPEN_FILE`, `RUN_PROGRAM`, `RUN_MACRO`, OLE verb, and slideshow
navigation. Inventory audio/video, OLE, embedded packages, and external
relationships without opening, following, activating, refreshing, or playing
them.

Presence after save does not prove runtime behavior. Require PowerPoint-native
verification when playback, action, animation, or link behavior matters.
